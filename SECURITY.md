# Security Policy / Politica di Sicurezza

> 🇬🇧 English below | 🇮🇹 Italiano sotto

## 🇬🇧 English

**Do not open public issues for vulnerabilities.**

- Report privately via GitHub Security Advisories (preferred).
- Include: affected version/commit, description, reproduction steps, impact.
- We aim to acknowledge within 72 hours.
- Please do not include secrets, tokens or API keys in any report.

Supported: latest release on `main` branch.

## 🇮🇹 Italiano

**Non aprire issue pubbliche per vulnerabilità.**

- Segnala in privato tramite GitHub Security Advisories (preferito).
- Includi: versione/commit, descrizione, passi per riprodurre, impatto.
- Obiettivo: risposta entro 72 ore.
- Non includere segreti, token o API key in nessuna segnalazione.

Supportata: ultima release sul branch `main`.
