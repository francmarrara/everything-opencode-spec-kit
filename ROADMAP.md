# Roadmap

> 🇬🇧 English below | 🇮🇹 Italiano sotto

## 🇬🇧 English

Goal: make this framework a reference for AI-assisted development with OpenCode + Spec Kit.

### Next (v0.2)

- [ ] CI badge + release automation
- [ ] 2-3 real example projects generated with `init-project.sh`
- [ ] Video/GIF demo in README (60-90 seconds)
- [ ] More agents: Python reviewer, DevOps specialist
- [ ] More MCP presets documented

### Mid-term (v0.3-v0.5)

- [ ] Benchmarks: Spec Kit workflow vs ad-hoc prompting
- [ ] i18n: full English docs, Italian courtesy translations
- [ ] Community: awesome-list PRs, blog posts, discussions enabled
- [ ] Compatibility matrix (OpenCode versions, Node versions, OS)

### Long-term (v1.0)

- [ ] Stable contracts for agents/skills/plugins with versioning
- [ ] Migration guides from Claude Code / other assistants
- [ ] 10+ external contributors, 500+ stars
