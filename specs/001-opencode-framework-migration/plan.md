# Implementation Plan: OpenCode + Spec Kit Framework Migration

**Branch**: `001-opencode-framework-migration` | **Date**: 2026-09-20 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-opencode-framework-migration/spec.md`

## Summary

Transform the `everything-claude-code` repository (9 agents, 15 commands, 11 skills, hooks, MCP configs, rules, tests, docs) into a reusable, native OpenCode + Spec Kit framework. The migration replaces 137+ Claude Code-specific assumptions (environment variables, tool names, hook events, file paths, APIs, metadata) with OpenCode-native equivalents while preserving engineering capabilities and maintaining strict Spec Kit / OpenCode separation.

## Technical Context

**Language/Version**: JavaScript/Node.js (existing scripts), Markdown (agents, skills, commands, rules)

**Primary Dependencies**: `@opencode-ai/plugin` (already in `.opencode/package.json`), Node.js standard library

**Storage**: File-system based (agents, skills, commands as Markdown files; configuration as JSON)

**Testing**: Node.js test runner (existing `tests/run-all.js` infrastructure)

**Target Platform**: Cross-platform (Linux, macOS, Windows) via Node.js

**Project Type**: Framework/plugin (OpenCode-native development environment)

**Performance Goals**: Context window efficiency (under 10 MCPs enabled, under 80 active tools)

**Constraints**: Must not depend on Claude Code runtime; must maintain strict `.specify/` / `.opencode/` separation; must preserve upstream MIT license and provenance

**Scale/Scope**: 9 agents, 15 commands, 11 skills, 6 hook categories, 14 MCP servers, 8 rules, 3 contexts, 12+ test files
